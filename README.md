- Subtraction
- Multiplication
- Division
- Modulus
- Decimal numbers
- Clear button
- Backspace button
- Keyboard support

## Technologies Used
- HTML
- CSS
- JavaScript

You can use the calculator by clicking the buttons or using your keyboard.
